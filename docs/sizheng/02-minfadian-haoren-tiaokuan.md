# 民法典"好人条款"与见义勇为的司法保障

## 案例背景

一段时间以来，"扶不扶""救不救"成为社会热议的话题。个别司法案件的处理曾引发公众对助人反被追责的担忧，一定程度上挫伤了人们见义勇为的积极性，"不敢救、不敢扶"的心理在社会上蔓延。

## 案例经过

2020年5月28日，十三届全国人大三次会议表决通过《中华人民共和国民法典》，自2021年1月1日起施行。这是新中国成立以来第一部以"法典"命名的法律，共7编1260条。

民法典第184条规定："因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任。"该条被通俗地称为"好人条款"，为自愿紧急救助者提供了完全的民事免责保障。与之呼应，第183条规定，因保护他人民事权益使自己受到损害的，由侵权人承担民事责任，受益人可以给予适当补偿；没有侵权人、侵权人逃逸或者无力承担民事责任时，受害人请求补偿的，受益人应当给予适当补偿，为见义勇为者解除了后顾之忧。

## 理论视角

"好人条款"体现了法治与德治的有机结合。法律是成文的道德，道德是内心的法律。民法典把见义勇为、诚信友善等社会主义核心价值观写入具体条文，用法治的力量引导社会崇德向善，正是"坚持依法治国和以德治国相结合"的生动实践。

从公民角度看，这一条款有助于提升公民法治素养：既要敢于救助、乐于助人，也要懂得法律对善行的保护机制，做社会主义法治的忠实崇尚者、自觉遵守者、坚定捍卫者。
