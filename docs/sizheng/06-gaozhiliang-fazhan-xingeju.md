# 高质量发展与新发展格局

## 案例背景

党的十八大以来，我国经济发展进入新常态，传统依靠要素投入、规模扩张的增长方式难以为继，发展方式转变、经济结构优化、增长动力转换成为迫切课题。

## 案例经过

2015年10月，党的十八届五中全会提出创新、协调、绿色、开放、共享的新发展理念。2017年10月，党的十九大作出我国经济已由高速增长阶段转向高质量发展阶段的重大判断。2020年，习近平总书记提出构建以国内大循环为主体、国内国际双循环相互促进的新发展格局，党的十九届五中全会将其写入"十四五"规划建议。

2022年10月，党的二十大进一步强调，高质量发展是全面建设社会主义现代化国家的首要任务。2023年9月，习近平总书记在黑龙江考察时首次提出"新质生产力"这一重要概念，指明其由技术革命性突破、生产要素创新性配置、产业深度转型升级而催生，特点是创新，关键在质优，本质是先进生产力。

在宏观政策协同发力下，2024年我国国内生产总值达134.9万亿元，比上年增长5%，经济总量稳居世界第二，对世界经济增长的贡献率保持在30%左右，继续成为世界经济增长的重要引擎。

## 理论视角

高质量发展是体现新发展理念的发展，是能够很好满足人民日益增长的美好生活需要的发展。新发展理念相互贯通、相互促进，是具有内在联系的集合体：创新发展注重解决发展动力问题，协调发展注重解决发展不平衡问题，绿色发展注重解决人与自然和谐问题，开放发展注重解决发展内外联动问题，共享发展注重解决社会公平正义问题。

构建新发展格局的关键在于经济循环的畅通无阻。以国内大循环为主体，绝不是关起门来封闭运行，而是通过发挥内需潜力，使国内市场和国际市场更好联通，实现更高水平的对外开放。发展新质生产力则是推动高质量发展的内在要求和重要着力点。
