# 十八洞村：精准扶贫的首倡地

## 案例背景

湖南省湘西土家族苗族自治州花垣县十八洞村，是一个藏在武陵山深处的苗寨。2013年，全村人均纯收入仅1668元，贫困发生率高，出行难、饮水难、增收难等问题突出，是典型的深度贫困村。

## 案例经过

2013年11月3日，习近平总书记来到十八洞村考察，首次提出"精准扶贫"重要理念，作出"实事求是、因地制宜、分类指导、精准扶贫"的重要指示。此后，十八洞村探索出一条精准识贫、精准帮扶的路子：通过精准识别确定贫困户并建档立卡；因地制宜发展猕猴桃种植（含"飞地经济"模式）、苗绣加工、山泉水厂、乡村旅游等产业；同时开展劳动力输出与技能培训。

2016年，十八洞村实现整村脱贫出列，人均纯收入从2013年的1668元增长到2020年的18369元，村集体经济从空白发展到年收入数百万元，从深度贫困村蝶变为全国脱贫攻坚示范村。

2021年2月25日，全国脱贫攻坚总结表彰大会宣告我国脱贫攻坚战取得全面胜利：现行标准下9899万农村贫困人口全部脱贫，832个贫困县全部摘帽，12.8万个贫困村全部出列，提前10年实现《联合国2030年可持续发展议程》减贫目标，创造了彪炳史册的人间奇迹。

## 理论视角

十八洞村的实践彰显了以人民为中心的发展思想——发展为了人民、发展依靠人民、发展成果由人民共享。精准扶贫方略坚持从实际出发，因人因地施策，体现了实事求是的思想路线和具体问题具体分析的方法论。

脱贫摘帽不是终点，而是新生活、新奋斗的起点。巩固拓展脱贫攻坚成果同乡村振兴有效衔接，朝着逐步实现全体人民共同富裕的目标稳步前进，正是新发展阶段解决发展不平衡不充分问题的必然要求。
